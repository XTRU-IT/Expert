# Expert Lounge

Рабочая программа кальянного мастера: столы, заказы, таймер замены углей, смены, чеки и статистика.

Работает в браузере телефона как приложение (PWA), без интернета. Все данные хранятся только в телефоне мастера; резервная копия — вкладка «Ещё» → «Сохранить копию».

## Установка на Android

1. Открыть ссылку на программу в Chrome.
2. Меню (⋮) → «Добавить на главный экран» / «Установить приложение».
3. Запускать с иконки Expert Lounge.

## Файлы

- `index.html` — вся программа.
- `sw.js` — офлайн-кэш.
- `manifest.webmanifest`, `icon-*.png` — установка на телефон.
